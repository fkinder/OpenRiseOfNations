## World::walk_data

@006b5cf0 · this: World · params: part · confidence: high · source: C.json

Addresses GameAccess::world (the global `world`) directly; this is ignored. part selects one section (1..13) or all (-1); every known caller (WalkDataGame, CheckSums::check_all, CheckSums::check_world) passes -1. Parts 5-9 use size/tile_size/fog_size/reg_size from part 4 (or from init when walked alone). Parts 10-13 walk Terrain (MiscAccess::terrain) members. start_city_locs (DynamicBitMask 0xf0) is not walked.

Open: With part >= 0 on load, World::init(xs, ys) still runs although xs/ys were only read for part 1 (stale values reused); irrelevant for the -1 callers.
